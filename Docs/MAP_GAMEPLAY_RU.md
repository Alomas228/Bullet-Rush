# Карты: разные боевые ситуации с общими оружием и апгрейдами

Реализованный этап от 29 октября 2026. Уровни открытия карт, награды, доступность оружия и эффектов сохранены. Новые контракты и отдельные системы экипировки не добавлены. Настройка требует игрового сравнения.

Следующий этап описан отдельно: [взаимодействия оружия и окружения для всех шести карт](MAP_WEAPON_INTERACTIONS_RU.md). Мокрота от прибоя и ледяной покров части небоссовых врагов в горах уже добавлены в код; параметры и статус проверок приведены в начале документа взаимодействий.

## Направления наступления

Раньше обычные волны на всех картах равновероятно выбирали окружение, фронт и фланги. Теперь у карты есть веса этих трёх направлений. На обычных волнах сохранён запрет повторения предыдущего направления; поэтому предпочтение не означает, что все волны будут одного типа. Все три варианта остаются в доступном наборе.

Специальная засада сохраняет фланговый заход: прежний повторный случайный выбор мог заменять его другим направлением. Боссы используют прежний отдельный путь с окружением. Правила появления типов врагов по номеру волны сохранены: карта не подмешивает танков и дальников раньше существующих порогов. Тема забега и архетип волны продолжают влиять на итоговый состав; процент подмешивания не равен конечной доле типа во всей волне.

## Опасности должны участвовать в текущем бою

- Первая полоса камнепада выбирается рядом с текущей позицией игрока со смещением 3,5–6 единиц по поперечной оси. Предупреждение сохранено; остальные полосы сохраняют случайный выбор. Камни уже наносят урон и врагам.
- Первый метеор выбирается в окрестности игрока, в кольце примерно 4,7–8,2 единицы при базовом радиусе удара 3,2. У границ карты координаты ограничиваются размером арены, поэтому точное расстояние может уменьшаться. Телеграф и время предупреждения сохранены. Дополнительные метеоры, если их число увеличено настройкой, используют прежний случайный выбор.
- Для опасностей берётся размер текущей арены из карты. При нулевой силе механики периодические опасности не запускаются. Частоты, число ударов и урон не повышены.
- Сохраняется ожидание завершения активного события волны перед запуском очередной опасности карты.

## Исправления транспорта и движения

У городской машины полоса предупреждения раньше рисовалась из позиции объекта по умолчанию и поперёк направления движения. Теперь объект получает центр дороги до создания телеграфа, а длинная ось предупреждения совпадает с направлением проезда. Предупреждение покрывает путь через арену.

Перед запуском транспорта проверяется свободная полоса с учётом ширины машины. Сначала ищется улица ближе к текущему бою, затем по арене. Если среди ограниченного числа попыток свободная полоса не найдена, этот проезд пропускается. Транспорт не должен систематически проезжать через игровые здания. Проверка учитывает коллайдеры `WorldStructure`; ручной декор без этого компонента не считается игровым препятствием.

Исправлено применение отрицательного бонуса скорости пустыни: ранее проверка `> 0` пропускала предусмотренное замедление игрока на 6%. Теперь оно применяется. Это небольшое изменение сложности, которое нужно проверить вместе с появлением быстрых врагов.

## Проверки и плейтест

Проверка чистой функции выбора направления выполнена отдельно на фактическом исходном коде: 36 036 проверок границ диапазона, исключения предыдущего направления и нейтрального выбора при нулевой силе. В редакторскую команду `ArcadeSurvivor → Checks → Combat regression` также добавлена проверка направлений.

Что обязательно проверить в Unity:

1. Город: предупреждение машины совпадает с её реальным проездом по свободной улице; на разных улицах не оказывается постоянно только одна центральная полоса.
2. Горы: камнепад виден рядом с боем, остаётся путь отхода, узкие проходы не запирают игрока.
3. Космос: предупреждение метеора остаётся читаемым у края арены; воронка даёт удобный момент для массовой атаки.
4. Пляж и пустыня: фланги заставляют выбирать позицию, но не создают постоянное окружение без выхода. В пустыне отдельно оценить замедление.
5. Каждую карту пройти стартовым оружием и покупной альтернативой при одинаковой постоянной прокачке. Отсутствие нужного эффекта не должно создавать непреодолимую проверку.

Изменённая геометрия применяется при новом построении арены. Для сравнения начинать новый забег, чтобы не использовать сохранённую раскладку текущего.
