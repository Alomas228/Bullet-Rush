# BulletRush — развитие забега

## Правила

- С обычной награды со второй волны одна карточка гарантированно предлагает доступную ветку (если такая осталась). Остальные карточки работают через текущий умный подбор.
- С пятой волны первое улучшение после волны для ещё не эволюционировавшего оружия — выбор его эволюции: фирменная и две случайные альтернативы класса. Подобранная эволюция существует до окончания забега и возвращается при повторном выборе того же ствола.
- После босса обычный выбор заменяется артефактом. Повторного получения одного артефакта нет. На финальном боссе награда нужна только при продолжении в бесконечный режим.
- У оружия бесконечный запас патронов, но конечный магазин. Автоматическая перезарядка после опустошения, R на ПК, нажатие на панель боезапаса на мобильном. Каждый отдельный залп тратит один патрон (дробь считается одним залпом). Магазин рассчитывается из базового темпа оружия, но его можно переопределить в WeaponData.
- PvP не использует эту систему, все временные эффекты сбрасываются при новом забеге.

## Ветки

| Стиль | Пример развития |
| --- | --- |
| Боезапас | Быстрые руки → Увеличенный магазин → Сборщик |
| Первый/последний залп | Быстрые руки → Первый выстрел → Последний патрон |
| Огонь | Зажигательные патроны → Катализатор → Дикий огонь |
| Электричество | Цепная молния → Проводник → Громовой крит |
| Кровь и восстановление | Кровотечение → Глубокие раны → Жатва крови |
| Взрывы | Взрывные патроны → Давление → Ударная волна |
| Рикошеты | Рикошет → Отражатель → Импульс |
| Контроль | Охлаждающие патроны → Раскол |
| Инженер | Способность → Боевой дрон → Турбодрон |
| Выживание | Защитные улучшения → Страж |
| Мобильность | Утилитарные улучшения → Мобильность |

Гибридные ветки: огонь/взрывы, огонь/электричество, кровь/вампиризм, рикошет/электричество, холод/электричество. Сохраняются прежние синергии проекта. Все дополнительные массовые эффекты ограничены числом целей или перезарядкой эффекта.

## Проверка

В редакторе Unity: `Tools → Bullet Rush → Validate Run Builds` — проверяет полноту карточек, доступность эволюций, магазины, ветки и сброс. Для проверки игрового поведения нужно пройти обычные волны 1–6, сменить оружие, победить первого босса, перезапустить забег и проверить ручную/автоматическую перезарядку на ПК и мобильном интерфейсе.
