Arcade

# Описание
Bullet Rush — это динамичная аркадная игра, в которой игрок оказывается на арене и сражается с бесконечными волнами врагов. 
Во время боя нужно постоянно двигаться, стрелять и выбирать улучшения, которые меняют стиль игры и делают персонажа сильнее. 
С каждой новой волной враги становятся опаснее, поэтому игроку приходится быстро принимать решения и подбирать подходящие улучшения. 
Цель игры — продержаться как можно дольше, набрать максимальное количество очков и побить свой рекорд.
